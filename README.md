# Cocktails for Android

Native Android preview · Android 10 or newer · Free direct downloads.

## Already using Cocktails Preview 1.0.0?

1. Download and install [Cocktails Preview 1.0.1 (bootstrap update)](https://github.com/vegscript/cocktails-android-downloads/releases/tag/android-preview-1.0.1-2) **over the existing app**.
2. Open Cocktails. In **Profile → App updates**, check for and install 1.0.2.
3. Future preview versions are offered directly in Cocktails.

Keep the existing app installed. The one-time bootstrap transfers its signing identity while preserving local bar data. Existing 1.0.0 installations need this step before 1.0.2. Android asks for installation approval; allow Cocktails as an installation source only when you choose to install an update.

## First installation

Start with [Cocktails Preview 1.0.2](https://github.com/vegscript/cocktails-android-downloads/releases/tag/android-preview-1.0.2-3). No GitHub account or USB cable is needed.

App updates show their version, notes and download size. Wi-Fi is the default; mobile data requires an explicit choice. Android confirms each installation. New cocktail content is delivered independently through the website's public content API.

The preview is separate from a future store release. This repository contains signed distribution files and public release metadata only, with no private source, credentials or user data.

## Bereits Version 1.0.0 installiert?

Einmal zuerst **1.0.1 über die vorhandene App installieren**, danach in Cocktails unter **Profil → App-Updates** auf 1.0.2 aktualisieren. Die App nicht deinstallieren. Ohne bisherige Installation kannst du direkt mit 1.0.2 beginnen. Danach erhältst du neue Preview-Versionen direkt in der App.
